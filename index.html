The method is the spine

This is what separates the module from any other bootcamp. It runs through every competency unit below.

Claude Code + a persistent “project brain.”

Each learner works with Claude Code as their AI pair, backed by their own pgVector project memory — a store that holds the game design, the code conventions, and every decision and bug they hit. The AI never loses the thread of the project, which is the only reason a beginner can ship in three months. Learners don’t just prompt — they run the loop, every session:

Competency units in detail

Each unit follows CoCU structure: work activities, related knowledge and skills, and the evidence a learner must produce to be judged Competent.

AGD·C01

AI-Assisted Development Foundation

24 hrs · Core
Operate the Todak AI method — Claude Code with a persistent project memory — to plan, build, verify and document work.
Work activities
  • Set up the AI development environment (Claude Code + pgVector memory)
  • Apply the prompt → plan → build → verify → save loop
  • Maintain project memory: design, conventions, decisions, defects
Related knowledge & skills
  • What an LLM, agent and agentic system is; context & memory
  • Structuring a prompt; recalling and verifying against memory
  • Version-control basics
Evidence: a working environment and one memory-driven task completed and documented in the project brain.
AGD·C02

Game Design Fundamentals

20 hrs · Core
Analyse game types and produce a scoped, buildable game design document.
Work activities
  • Analyse genres, core loops and player motivation
  • Evaluate scope and feasibility for a 12-week build
  • Define a concept and produce a 1-page GDD
Related knowledge & skills
  • Core loop, feedback and reward; genre conventions
  • Scope discipline — why small games win
  • Design-document writing
Evidence: an approved 1-page game design document.
AGD·C03

Game Programming with Godot

40 hrs · Core
Build 2D game logic in Godot 4 with GDScript, AI-assisted throughout.
Work activities
  • Use the Godot editor: nodes and the scene system
  • Write GDScript: variables, signals, input, physics, collision
  • Implement sprites and animation; debug systematically
Related knowledge & skills
  • Programming logic fundamentals
  • Godot architecture; event-driven signals
  • Reading errors and verifying AI-assisted fixes
Evidence: a playable 2D platformer with lose and win states.
AGD·C04

Game Application Development & Build

36 hrs · Core
Structure a game as a real application and produce a build that runs on a device.
Work activities
  • Implement state machine, scene management, save/load, settings, UI/HUD
  • Apply version control to the project
  • Export to Android and test on a physical device
Related knowledge & skills
  • Application architecture and game state
  • Persistence and configuration
  • Build & export pipeline; on-device debugging
Evidence: a multi-level game with menu and save, running from an installable build.
AGD·E05

3D Asset Creation Pipeline

28 hrs · Elective (3D)
Produce game-ready 3D assets using an AI-assisted pipeline on Todak’s own hardware.
Work activities
  • Generate a 3D model from AI and evaluate output
  • Clean up and retopologise in Blender
  • Maintain art-style consistency; import into Godot
Related knowledge & skills
  • 3D asset fundamentals; mesh & texture
  • AI generation workflow and its limits
  • Blender cleanup; engine import settings
Evidence: one AI-generated 3D asset, cleaned and running in-engine.
AGD·E06

Character Rigging & Animation

32 hrs · Elective (3D)
Rig and animate a 3D character and integrate it into the game engine.
Work activities
  • Build an armature/skeleton and apply weight-painting
  • Create animation states — idle, walk, jump
  • Export the rigged character cleanly to Godot
Related knowledge & skills
  • Rigging concepts; bones and weights
  • Animation state machines
  • Skeletal export and engine integration
Evidence: a rigged character animating inside a Godot scene.
AGD·C07

Game Production — Vertical Slice

40 hrs · Core
Produce a polished, end-to-end vertical slice ready for review.
Work activities
  • Lock scope to one core loop and build it fully
  • Apply game feel: juice, particles, transitions
  • Integrate audio and SFX; iterate via weekly builds
Related knowledge & skills
  • Production discipline and scope control
  • Game feel and polish techniques
  • Playtesting and iteration
Evidence: a polished vertical slice / release candidate.
AGD·C08

Game Publishing & Distribution

20 hrs · Core
Prepare and publish a game to a distribution platform in compliance with platform and AI-disclosure policy.
Work activities
  • Prepare the store listing kit — icon, screenshots, trailer, copy
  • Complete AI-content disclosure and age rating
  • Submit via the publisher account and verify the game is live
Related knowledge & skills
  • Store policies and submission flow
  • AI-disclosure and compliance requirements
  • Release readiness and quality-gate criteria
Evidence: a game published (or quality-gate-ready) with a complete store listing.

06

Assessment & certification

Competency-based, evidenced by a real game

Every unit is judged Competent / Not Yet Competent against the evidence above — there are no written exams. The learner’s portfolio (their project memory, builds and assets) is the running record, and the published game is the capstone evidence, gated by the Todak Studios quality review.

Learners who complete all Core units earn the module credential; the 3D pathway (Elective units E05–E06) is stacked on top for those who take the 3D route. Units are designed to be individually recognisable as stackable micro-credentials.

07

TVET alignment

Structured to JPK CoCU — accreditation-ready

This module is written in the Curriculum of Competency Unit (CoCU) structure used by Malaysia’s Department of Skills Development (JPK/DSD): competency units split into work activities, related knowledge and skills, indicative training hours, and competency-based assessment. It is positioned as a stackable micro-credential cluster toward Sijil Kemahiran Malaysia (SKM) Level 3 in a Game / Interactive Multimedia occupational area, leveraging Todak Academy’s existing JPK accredited-centre status.

Status: this is a draft specification. Unit codes, hour allocations and the SKM mapping are indicative and become official only on JPK accreditation. It is not yet an accredited NOSS, and the accreditation pathway (and any MARA / PTPK / HRD Corp funding) is a separate step.
