# course.neotodak.com

Public course / module specification pages for the **Todak AI Creator Program**.

## Pages
- `index.html` — **AI-Assisted Game Development** (Game Track) module spec. 12-week, competency-based module built on the Todak method (Claude Code + pgVector project memory), structured to Malaysian **JPK CoCU** format. A graduate ships one published game.

## Deploy
Static site. Pushing to `main` triggers a GitHub Action that deploys to Netlify (`git push` = deploy). No build step.

Live: https://course.neotodak.com
